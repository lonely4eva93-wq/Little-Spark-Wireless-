# Little Spark Wireless Launch Checklist ⚡

Use this checklist before moving from prototype to real users, payments, or wireless activation.

## 1. Product Readiness

- [ ] Confirm brand name and domain
- [ ] Replace demo copy with final customer-facing copy
- [ ] Add real FAQ
- [ ] Add customer support contact method
- [ ] Add onboarding walkthrough
- [ ] Test on iPhone Safari
- [ ] Test on Android Chrome
- [ ] Test install-to-home-screen flow

## 2. Backend Readiness

- [ ] Choose Firebase, Supabase, or another backend
- [ ] Add real authentication
- [ ] Add user roles: customer, owner, security/admin
- [ ] Move all sensitive logic server-side
- [ ] Replace localStorage with cloud database
- [ ] Add backup and export process
- [ ] Add logging and error monitoring

## 3. Payment Readiness

- [ ] Choose Stripe, Square, PayPal, or another payment provider
- [ ] Build checkout flow
- [ ] Build subscription management
- [ ] Add cancellation flow
- [ ] Add refund handling
- [ ] Add tax settings
- [ ] Add payment receipt emails
- [ ] Add fraud/risk review rules

## 4. Wireless / eSIM Readiness

- [ ] Choose an eSIM or wireless provider API
- [ ] Confirm reseller or partner agreement
- [ ] Document activation workflow
- [ ] Add identity verification where required
- [ ] Add device compatibility checks
- [ ] Add activation status tracking
- [ ] Add customer support escalation process

## 5. Legal / Compliance

- [ ] Final privacy policy
- [ ] Final terms of service
- [ ] Refund policy
- [ ] Acceptable use policy
- [ ] Telecom/provider compliance review
- [ ] Payment compliance review
- [ ] Data retention policy
- [ ] Security incident process

## 6. Security

- [ ] Remove demo PINs
- [ ] Add real admin authentication
- [ ] Add environment variables for secrets
- [ ] Add rate limiting
- [ ] Add input validation
- [ ] Add audit logs
- [ ] Add admin action history
- [ ] Add secure HTTPS hosting

## 7. Growth

- [ ] Connect referral links to real accounts
- [ ] Add referral reward rules
- [ ] Add email capture automation
- [ ] Add social preview image
- [ ] Add analytics events
- [ ] Add conversion tracking
- [ ] Build launch TikTok/Reels ads

## 8. Final Smoke Test

- [ ] User can sign up
- [ ] User can choose a plan
- [ ] User can pay
- [ ] User can receive confirmation
- [ ] Owner can view customer activity
- [ ] Support can handle tickets
- [ ] Security can flag risks
- [ ] User can cancel or request support

## Notes

This prototype is a strong starting shell. Real wireless service requires provider agreements, secure backend infrastructure, payment compliance, privacy terms, and legal review before selling to the public.
