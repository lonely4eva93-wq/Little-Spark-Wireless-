# Privacy & Terms Notes ⚖️

These notes are placeholders for the future production version of Little Spark Wireless.

The current prototype stores demo information locally inside the browser using localStorage.

No real telecom activation, payment processing, or secure authentication currently exists.

---

# Privacy Notes

Future production versions should clearly explain:

- What customer data is collected
- Why the data is collected
- How customer data is stored
- Who can access the data
- How long data is retained
- How users can delete accounts or request deletion
- Whether referral systems track invitations
- Whether analytics or cookies are used
- What third-party providers are connected

Examples of future providers may include:
- payment processors
- analytics providers
- authentication providers
- telecom/eSIM vendors
- customer support tools

---

# Terms Notes

Future production terms should explain:

- acceptable use rules
- billing and subscription terms
- cancellation policies
- refund handling
- activation limitations
- device compatibility
- service interruptions
- support expectations
- fraud prevention actions
- account suspension rules

---

# Security Notes

Production launch should include:

- secure backend authentication
- encrypted connections
- protected API secrets
- audit logging
- rate limiting
- admin permission controls
- fraud monitoring
- account recovery systems

---

# Telecom / eSIM Notes

Real wireless activation requires:

- provider agreements
- reseller authorization
- compatible device workflows
- telecom compliance review
- customer identity verification where applicable

---

# Prototype Reminder

Little Spark Wireless is currently a front-end concept prototype and should not be treated as a production telecom platform yet.

The purpose of this prototype is:
- design exploration
- onboarding flow testing
- founder acquisition
- investor demonstrations
- future provider planning
