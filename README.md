# Little Spark Wireless

Little Spark Wireless is the first starter build for an AI-assisted wireless/eSIM concept.

## What is in this repo

- A responsive landing/app shell
- Working front-end chat/send button behavior
- localStorage saved messages and leads
- Owner/Admin placeholder panel
- Provider API integration notes

## Current status

This is the first initialized version. It is front-end only and does not yet include a real eSIM provider API, payments, authentication, or backend security.

## Next build steps

1. Add real provider API credentials on a backend server.
2. Add user accounts and owner login.
3. Add payment provider integration.
4. Add support/ticket system.
5. Add deployment configuration.

## Safety note

This app cannot control a user's whole phone. iOS and Android restrict that for privacy and security. The safe version can manage app features, account settings, support flows, plan purchases, and provider API actions that users authorize.
